# 双人号池容量估算：DeepSeek V4.1 Flash 与 Gemini 4 Argon

> 数据采集：2026-10-26 · 实测窗口 16.2 小时 · 口径为「等效 API 用量额度」，非现金。
> 本文所有官方数字均带来源；社区的实测数字标注了时间，因为 Go 的额度结构在 2026 年 8 月、9 月改过两次。

## TL;DR

| 目标 | 配置 | 月成本 | 依据 |
|---|---|---|---|
| 两人 DeepSeek 用不完 | **5 个 Go**（重度 3 并发）～ 8 个（4~5 并发） | $50 ~ $80 | 实测 $0.213/小时 × 600 小时 ÷ $80 单号额度 |
| Argon 大量用 + 免费模型要并发 | **2~4 个 Devin Pro** | $40 ~ $80 | 免费模型限流是按号计，并发数 ≈ 号数 |
| 合计起点 | 5 Go + 2 Pro | **$90/月** | 缓存命中 ≥ 93% 的前提 |

三个反直觉的结论先说：

1. **号数是缓存命中率的函数，不是用量的函数。** 同一份 Go 订阅，缓存命中从 97% 掉到 0%，要撑住同样用量需要从 3 个号涨到 38 个。
2. **SWE-2 的免费状态官方自相矛盾。** pricing 页写「免费使用 SWE-2」，desktop/models 文档写「免费到 2026-10-15，之后按 $3/$15 计费」。见第 5 节。
3. **Devin Pro 的号数由并发决定，不由额度决定。** 免费模型的 `Reached free model rate limit` 是按号限流，N 个号 = N 份并发额度。

## 1. 实测基线

本池（CPA + opencode2api + 4 个 Go key）2026-10-26 的 16.2 小时真实流量：

| 指标 | 实测值 |
|---|---|
| 请求数 | 1,329 |
| 请求速率 | **82 请求/小时** |
| 输入 token | 130,170,341（**97,946/请求**） |
| 缓存命中 | 124,352,768（**95.53%**） |
| 输出 token | 799,994（602/请求） |
| 等效成本 | **$3.45 / 16.2h = $0.213/小时** |
| 单请求成本 | **$2.60 milli** |
| 上游成功率 | 1,320/1,329 = 99.3% |

四个 key 的负载分布：OVCdF 567 / qkXkc 325 / UZiCs 346 / y0vd8 88 次，加权轮询正常。

注意这里的请求形态是**单流**：82 请求/小时、10 万上下文。双人重度多并发会把这两项都推高，见第 3 节。

## 2. 成本模型与单价

单请求成本 = 未命中输入 × 输入单价 + 缓存读 × 缓存单价 + 输出 × 输出单价。

### DeepSeek V4.1 Flash（OpenCode Zen 口径）

| 项目 | 单价（$/1M token） |
|---|---|
| 输入 | 0.30 |
| 输出 | 1.20 |
| **缓存读** | **0.006** |

缓存读比未命中便宜 **50 倍**——这就是为什么命中率是唯一杠杆。

### Gemini 4 Argon（三档时效价）

官方模型页明示的阶梯：

| 时段 | 输入 | 输出 | 缓存读 | 单请求成本（180k/1.5k/93%） |
|---|---|---|---|---|
| ≤ 2026-10-27 | $1.00 | $5.00 | $0.05 | **$28.5 milli** |
| 10/28 ~ 12/01 | $2.00 | $10.00 | $0.10 | $56.9 milli |
| ≥ 2026-12-02 | $4.00 | $20.00 | $0.20 | **$113.9 milli** |

四十天内单价翻四倍。做长期规划必须按 **$4/$20** 那一档算。

## 3. DeepSeek：需要几个 Go

### 单号真实产能

Go 的额度是美元窗口（官方 FAQ）：**每月 100%，每 5 小时 20%，每周 50%**。DeepSeek V4.1 Flash 的单号月额度为 $80，5 小时窗口 $16。

按重度形态单请求 $6.58 milli：

| 窗口 | 额度 | 可承载 |
|---|---|---|
| 月 | $80 | **12,150 请求/月** ≈ 405 请求/天 |
| 5 小时 | $16 | 2,430 请求/5h ≈ 486 请求/h |

**月窗口先撞墙，5 小时窗口不是瓶颈。**

### 两人 300h/月（10h × 30d）的号数

请求形态：180k 上下文 / 1.5k 输出 / 93% 命中。

| 场景 | req/h·人 | 月请求 | 月成本 | Go 号 | Go Plus 号 |
|---|---|---|---|---|---|
| 轻度（边聊边写） | 15 | 9,000 | $59 | 1 | 0.4 |
| 正常深度 | 40 | 24,000 | $158 | **2** | 1 |

### 缓存命中率敏感性

## 4. Argon：需要几个 Devin Pro

### 并发维度（本方案的主要理由）

Devin 的免费模型限流是**按号、按请求作用域**的，命中后该号进入冷却而不是全池失败——CPA 侧由 `oauth.request-scoped-errors` 实现：
````
status: 429 / 500
match: Reached free model rate limit / resource_exhausted
action: continue-and-cooldown
````

这意味着：**池子的有效并发度 ≈ Devin 号数**。两个人在多个 agent/子代理里同时跑免费模型时，单号会被限流打到冷却，多开 Pro 号是唯一直接的扩容手段。按每人常驻 2~3 个并发 agent、留 1 个号的余量：

| 每人常驻并发 | 需要 Pro 号 |
|---|---|
| 1~2 | 2 |
| 3~4 | 4 |
| 6+ | 6 以上，且要配静态出口 |

### 额度维度（Argon 本身）

Devin Pro 的额度是**按 token 计的 daily + weekly 预算**，官方从不公开数值（limithit 查证结论：「size not published」）。唯一可用的是官方 WindSurf 时代估算：Premium 模型（Gemini Pro 类，含 Argon）**Pro 档 8~101 条/天，Max 档 47~631 条/天**，另加周限额。

区间跨 12 倍，无法精确算号数。做法是开一个号实测一周，用真实「条/天」反推。

### Devin Pro 与 Go 跑 Argon 的性价比

| 渠道 | 月成本 | Argon 可用量 | 单次成本 |
|---|---|---|---|
| Devin Pro | $20 | 8~101 条/天（官方估算） | $0.0002 ~ 0.0028 |
| OpenCode Go | $10 | 月额度 $30 ÷ $56.9m ≈ **527 请求** | $0.019 |

Argon 走 Devin Pro 比走 Go 便宜 7~90 倍。**Argon 不该用 Go 跑**，Go 只留给 DeepSeek。

## 5. SWE-2 免费状态：官方自相矛盾

两处一手来源给出冲突的说明：

| 来源 | 原文 |
|---|---|
| [devin.ai/pricing](https://devin.ai/pricing)（2026-10-26 截屏） | 「免费使用 SWE-2」，列在 Pro 的计划功能里，未标截止 |
| [docs.devin.ai/desktop/models](https://docs.devin.ai/desktop/models.md) | 「SWE-2 is free for self-serve plans **through October 15, 2026**. List pricing ($3.00/1M input, $15.00/1M output, $0.30/1M cache input) applies afterward.」 |

第三方变更追踪站 PlanYield 也记录了这个终止日期（2026-10-16 条目）。

**结论：按「可能收费」规划，按「目前免费」使用。** 若开始计费，SWE-2 的 $3/$15 单价是 DeepSeek 的 10 倍，单请求约 $110 milli——它会从「无限通道」变成「比 Argon 还贵的通道」。此时应立即把所有 SWE-2 路由切回 DeepSeek。

检测办法：白嫖量突降时看 CPA 的 `auth-files` 里 Devin 凭据的 quota signals，或直接在 Devin Desktop 用量表里看 SWE-2 是否开始扣额度。

## 7. 风控边界

| 事件 | 来源 |
|---|---|
| 账号因「fraud / breach of ToS」被封，订阅仍自动续费 | [GitHub #46515](https://github.com/anomalyco/opencode/issues/46515)（2026-09-01） |
| 用户「开了多个账号，全部显示 Request blocked by upstream provider」 | [GitHub #40055](https://github.com/anomalyco/opencode/issues/40055)（2026-08-01） |

已知的触发因素：链式自邀、同一支付方式批量开号、同设备指纹、多号共用单一 IP。

**操作边界**：

- 4~5 个号走 `direct` 尚可；
- **6 个号以上必须先铺 2~3 个静态 SOCKS5/HTTP 出口，单号单出口**；
- 代理必须是静态的，不能在 URL 末尾加 `#pool`——否则 key 与 IP 的绑定会漂移，缓存和风控双重受损。

另外注意：Go 是**单成员 workspace**（官方原文：A workspace with a Go subscription cannot invite members），两人不能共用一个号，结构上必须靠 CPA 聚合多号，这正是本项目的形态。

## 8. 行动清单

| 优先级 | 动作 | 理由 |
|---|---|---|
| P0 | 把 `prompt_cache_key` 固定在会话级、system prompt 去掉时间戳/随机 ID | 命中率 95% → 85% 等于号数翻倍 |
| P0 | 4 个号保留 `direct`，扩到 6 个前先铺静态出口 | 封号不可逆，且会连坐 |
| P1 | 加第 5 个 Go 号 | 重度 3 并发的实测需求线 |
| P1 | 开 2 个 Devin Pro | 同时满足 Argon 额度与免费模型并发两条 |
| P2 | 用 1 个号实测一周 Devin 的「条/天」真实值 | 官方 8~101 区间太宽，无法规划 |
| P2 | 在 CPA 侧观察 SWE-2 是否开始计费 | 见第 5 节，官方口径冲突 |
| P3 | 若 Argon 用量继续增长，12/01 前重新核价 | $2/$10 → $4/$20，成本翻倍 |

## 9. 未证实 / 已知空白

- **Devin Pro 的额度数值**：官方从未公布，第三方追踪站明确写「size not published」。所有「8~101 条/天」都源自 2026-03 的 WindSurf 估算，且是按消息数而非 token 数。
- **SWE-2 免费的真实截止日**：官方两处文档冲突，无法判断哪个生效。
- **Argon 在 Devin 的计费口径**：走 Devin Desktop 的 quota/超额（API list price），与 Devin Cloud 的 ACU 是两套账；同一 Pro 订阅里两者是否共享预算未证实。
- **Go 的 5 小时/周窗口当前是否仍是 20%/50%**：官方 FAQ 如此表述，但 8 月刚改过一次，未逐日核对。
- **Reddit / X 的一手英文帖**：本次采集时这两个渠道的公开抓取报 SSL 证书链错误（非平台登录限制），仅通过聚合站拿到二手快照。

## 附：复算方法

````bash
# 实时余量
ssh orca-pool 'cd /opt/orca-ai-pool && python3 scripts/poolctl.py quota'

# 请求形态与缓存命中（opencode2api 内部指标）
ssh orca-pool 'curl -s -b /tmp/ck http://127.0.0.1:18081/api/monitor' \
  | python3 -c 'import json,sys; d=json.load(sys.stdin); print(d["usage"]["lifetime"]["tokens"])'
````

单请求成本 = (未命中输入 × 0.30 + 缓存读 × 0.006 + 输出 × 1.20) ÷ 1e6，单位美元。

号数 = ⌈月总成本 ÷ 单号月额度⌉，并取 5 小时窗口的下界。
